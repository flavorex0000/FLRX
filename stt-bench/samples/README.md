# 샘플 준비

```
samples/
├── ko/       한국어 강의
├── mixed/    한국어 + 영어 혼용 강의
└── en/       영어 강의
```

- 음성 파일: `wav, mp3, m4a, flac, ogg, opus, webm, mp4, aac`. 이름은 자유. 예: `ko/회로이론_5주차.m4a`
- 정답 전사본: 음성과 **같은 이름의 `.txt`**. 예: `ko/회로이론_5주차.txt`
  - 정답이 없어도 전사는 되지만, 점수(CER/WER/MER·용어·숫자)는 정답이 있어야 나옵니다.
  - 영어 전공용어는 **원하는 표기 그대로**(예: `MOSFET`, `op-amp`) 적으세요. `term_exact` 는 정답과 같은 표기인지로 채점합니다.
  - 숫자·단위는 아라비아 숫자로 통일하면 숫자 채점이 정확해집니다. 예: `0.7 V`, `10 kΩ`, `2 mA/V`
  - 한 서비스의 결과를 고쳐서 정답을 만들면 그 서비스에 유리해집니다. 가능하면 두세 서비스의 결과를 대조하며 직접 들으면서 고치세요.

긴 강의에서 5분 구간만 잘라 쓰려면:

```bash
python -m stt_bench clip ~/강의/회로이론_5주차.m4a 12:30 5:00 samples/mixed/회로이론_5주차_1230.mp3
```

이 폴더의 음성과 전사본은 `.gitignore` 로 커밋에서 제외됩니다 (강의 저작권·개인정보 보호).
